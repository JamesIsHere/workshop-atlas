Preparing a File for e-Signing

In order to prepare a file for e-signing you will need to:

  1. Indicate all parties that will be signing the document.

  2. Add all necessary fields for the e-signature file.

Below, we will go over how to complete each step involved in this process.

Adding Signers to an e-Signature File

In order to add/remove signers to/from a file for e-signing, you will need to follow the steps below:

  1. From the Files index, click the 🪶 feather icon when mousing over the file.

  2. Add all parties that will be signing the document in the e-Signature Setup modal.

  3. Proceed by clicking the Prepare/Edit Signature Document button.

✅ Important Notes:

  • You can add/remove signers to/from the document up until signatures have been requested on this document.

  • Only PDF Documents can be prepared for e-signing.

  • If the PDF uploaded to Docketwise has PDF editing restricted in any way, the e-signed PDF will not be able to be downloaded due to compatibility issues.

Adding Fields to an e-Signature File

After clicking the Prepare/Edit Signature Document button from the e-Signature Setup modal (above), you will be navigated to the Prepare e-Signature File page. Here, you can add, edit, and assign fields to the signers.

Adding Fields

To add a field, simply select the field type you would like to include and click wherever in the document you would like to place it.

Assigning Fields

After placing each field, it will need to be assigned to one of the indicated signers. To do this, simply select the field and choose who it will be related to under Field Details.

Deleting Fields

If you need to delete any fields, simply click and select the field you would like to delete and click the 🗑️ trashcan icon under Field Details.

Saving the e-Signature File Draft

Once you have placed and assigned the fields on the e-Signature file, click the Save & Continue → button to save your e-Signature file.

✅ Note: You can edit the fields in the e-signature file up until signatures have been requested on this document. If you wish to keep editing, you can close the Send e-Signature Request modal and return to editing later.

Requesting Signatures on an e-Signature File

After clicking the Save & Continue → button from the Prepare e-Signature File page, the Send e-Signature Request modal will appear, allowing you to send e-signature requests.

You can also open the Send e-Signature Request modal by clicking on the bell 🔔 icon when mousing over the file.

From here, you can send (and re-send) an e-signature request by:

  1. Selecting the Email and/or SMS checkboxes for each individual that still needs to sign.

  2. Clicking the Send to Unsigned button.

After clicking the Send to Unsigned button, each selected signer will receive an e-signature request via the email and/or SMS (whichever were indicated).

🚨Note: After sending out an e-signature request, you will no longer be able to make edits to the e-signature file.

[Navigate back to Contents]

Signing an e-Signature File

After a signer's signature is requested, they will receive a secure link to sign the document. After accessing this link, the signer may complete their required fields.

Firm members on the same Docketwise account may also sign by clicking on the Sign button for the e-signature file.

To complete the required fields, simply click the field in the document and complete enter your signature, initials, or text (depending on the field).

✅ Notes:

  • Signature and initial fields can either be drawn or typed out.

  • Date fields will be populated automatically according to the device's date.

[Navigate back to Contents]

Completed e-Signature Files

After signing their portion of the e-signature file, the signer will receive a copy of the e-signature file with their completed portion.

After all signers have completer their portions of the e-signature file, they will all receive a copy of the completed e-signature file.

e-Signature Status

In the Files index, the e-Signature Status Column will display the current status for each e-signature file.

If the signature requests have been sent and are still pending, you can see who still needs to sign by mousing over the status.

Additionally, you filter your e-signature files according to their e-Signature Status. To do this, simply select the e-Signature Status that you want to filter to from the Files index.
