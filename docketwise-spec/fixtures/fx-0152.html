Workflows with Matter Types and Statuses

Workflows make it easy to stay on track as your matters progress.

June 8, 2026
Table of contents

Overview

Matter Types and Matter Statuses enable you to build custom workflows for each of your matters. These Matter Types and Statuses can be used to:

  • Create automations triggered by a Matter's Status.

  • Track the progression of your Matter.

  • Filter your matters in the Matters Dashboard by:

    • Matter Type

    • Matter Status

    • Late Status (based on the duration that you set for each status).

  • Used as filters in Matters Reports.

Creating a New Matter Type

In order to create a Matter Workflow, you will need to follow the steps below:

  1. Navigate to Settings > Features > Matter Workflows.

  2. Click the "New Workflow+" button button.

  3. Enter a Matter Type name.

  4. Duplicate an existing Matter Type* (optional).

  5. Click the Create matter type button.

Creating and Importing Matter Statuses

Matter Statuses can be added to a Matter type by either creating a status or importing an existing status.

In order to add Statuses for a Matter Type, you will need to follow the steps below:

  1. Navigate to Settings > Features > Matter Workflows.

  2. Click the Create Status button under the Matter Type to which you would like to add a status.

  3. Name the Status.

  4. Set the duration on how long a matter should stay in the status* (optional).

  5. Set automations to be triggered by a Matter being put into this status* (optional).

    1. Add Task List: Imports an existing Task List.

    2. Send Message: Sends a message from an existing Message Template to the Matter's primary contact.

    3. CC the matter's applicant on the emailed message.

    4. Move to the next status once all tasks are complete.

  6. Click the Save button.

To import an existing Status to a Matter Type, you will need to follow the steps below:

  1. Navigate to Settings > Features > Matter Workflows.

  2. Click the Import Status button under the Matter Type to which you would like to add a status.

  3. Select the Status from the drop-down list.

  4. Check the box to include the status' automations* (optional).

  5. Click the Import Status button.

Editing Matter Types and Matter Statuses

Reordering the Sequence of Matter Statuses

In order to reorder the sequence of your Matter Statuses, you will need to follow the steps below:

  1. Navigate to Settings > Features > Matter Workflows.

  2. Drag and drop your Matter Statuses under a given Matter Type.

Editing an Existing Matter Type

In order to edit an existing Matter Type, you will need to follow the steps below:

  1. Navigate to Settings > Features > Matter Workflows.

  2. Click the Pencil Icon next to the Matter Type's name that you would like to update.

  3. Enter the name to which you would like to rename your Matter Type.

  4. Click the Create Matter Type button.

Deleting an Existing Matter Type

In order to delete an existing Matter Type, you will need to follow the steps below:

  1. Navigate to Settings > Features > Matter Workflows.

  2. Click the X icon next to the Matter Type that you would like to delete.

Editing a Matter Status

In order to edit a Matter Status, you will need to follow the steps below:

  1. Navigate to Settings > Features > Matter Workflows.

  2. Click the Edit link next to the Matter Status that you would like to update.

  3. Make any edits for the Name, Duration, and Automations.

  4. Click the Save button.

Note: If the Matter Status' name is shared across other Matter Types, updating its name will update all statuses with that name to the new name indicated. Durations and automations will remain unique for each status regardless of a share status name.

Removing a Matter Status from a Matter Type

In order to remove a Matter Status from a Matter Type, you will need to follow the steps below:

  1. Navigate to Settings > Features > Matter Workflows.

  2. Click the Edit link next to the Matter Status that you would like to update.

  3. Click the Remove from Matter Type button.

Deleting a Matter Status

In order to delete a Matter Status, you will need to follow the steps below:

  1. Navigate to Settings > Features > Matter Workflows.

  2. Click the Edit link next to the Matter Status that you would like to update.

  3. Click the Delete button.

Note: If the Matter Status' name is shared across other Matter Types, deleting this status will delete ALL other statuses with that share name.

Matter Workflow Automations

As mentioned above, you are able to have a Matter Status tied to automations that can:

  • Add Task List: Imports an existing Task List.

  • Send Message: Sends a message from an existing Message Template.

  • CC the matter's applicant on the emailed message.

  • Move to the next status once all tasks are complete.

After automations are set to a Matter Status, you are ready to automate! Once a Matter in this Matter Type starts in or is updated to said Matter Status, the associated automations will be triggered.

You can even add another layer of automation by automatically having Tasks automatically shared to the client's portal!

Setting a Matter's Type and Status

A Matter's Type and Status may be set when creating a matter or by editing a Matter that is already made.

To set a Matter's Type and Status when creating a new Matter, you will need to follow the steps below:

  1. Click the Create New ▼ button from your Docketwise Dashboard.

  2. Select the the Matter Type and Matter Status (after choosing the Matter Type, the first Matter Status in the sequence will populate, which can be changed).

  3. Click the Create Matter → button.

In order to set a Matter's Type and Status after it is already created, you will need to follow the steps below:

  1. Navigate to the Matter for which you would like to set a Matter Type.

  2. Click on the Update Matter Details link.

  3. Select the the Matter Type and Matter Status (after choosing the Matter Type, the first Matter Status in the sequence will populate, which can be changed).

  4. Click the Update Matter → button.

Updating a Matter's Status

Once you have set your Matter's Type, you can easily update the Matter's Status as it progresses through your each of the steps. In order to update, your Matter's Status, you will need to follow the steps below:

  1. Navigate to the Matter for which you would like to update the status.

  2. Click the Status in the Matter Workflow progress bar to that of which you wish to update.

Tracking a Matter's Status

When in the Matter's Overview Page, you are able to track the status of a Matter and can tell if the Matter has been sitting in a certain status for too long.

You will see a progress bar indicating the current Status of the matter.

When a Matter is on time (has not met/exceeded the current Matter Status' set duration), the status bar will be green.

When a Matter is late (has met/exceeded the current Matter Status' set duration), the status bar will be red.

Filtering the Matters Dashboard

In order to filter your Matters Dashboard based on Matter Type and/or Matter Status, you will need to follow the steps below:

  1. Navigate to your Matters Dashboard.

  2. Click the Filter button.

  3. Choose the value(s) that you would like to filter under Matter Types ▼, Matter Statuses ▼, and/or Late Status ▼.

  4. Click the Submit button.

Note: If the Matter Status' name is shared across other Matter Types filtering for just the Matter Status will show this status across all Matter Types unless a Matter Type is indicated.

Filtering Matter Reports

In order to filter your Matters Reports based on Matter Type and/or Matter Status, you will need to follow the steps below:

  1. Click the Create New ▼ button from your Docketwise Dashboard.

  2. Click the Report option.

  3. Choose the Matter Report that you would like to run.

  4. Choose the value(s) that you would like to filter under Matter Types ▼, Matter Statuses ▼, and/or Late Status ▼.

  5. Click the Update button.

Note: If the Matter Status' name is shared across other Matter Types filtering for just the Matter Status will show this status across all Matter Types unless a Matter Type is indicated.
