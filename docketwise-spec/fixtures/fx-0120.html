How Zapier Works

Zapier is an online automation tool that connects your apps and lets you automate processes by creating Zaps with a Trigger event and a subsequent Action event (or events).

  • A Zap is simply an automation created in Zapier, which is initiated by a Trigger event and causing subsequent Actions.

    • A Trigger is an event that happens in one app, which will activate the Zap

    • A subsequent Action is an event that will will take place within a designated and connected app after the Zap has been triggered

Another way to think of it is: When this (trigger) happens do that (action).

Connecting Docketwise to Zapier

In order to add Docketwise as a connected app in Zapier, you will need to follow the instructions below:

  1. Log in to your Docketwise account

  2. Navigate to the My Apps tab in Zapier

  3. Click the Add Connection button

  4. Enter Docketwise into the search bar

  5. Select Docketwise

  6. Authorize the connection

Creating Zaps with Docketwise

As mentioned above, you can create a Zap using an event in Docketwise as a trigger or have an event in another app trigger a subsequent event in Docketwise.

To start creating a Zap with Docketwise, you will want to start by following the steps below:

  1. Navigate to your Zapier Dashboard

  2. Click the Make a Zap button

  3. Creating the Trigger

    1. Choose the App that will trigger the Zap

    2. Choose the Trigger Event

    3. Click the Continue button

    4. Select the Account

    5. Click the Continue button

    6. Test the trigger by clicking the Test Trigger button

  4. Creating the Action(s)

    1. To add the action, either click the + icon or the empty Action

    2. Choose the App in which the action will take place

    3. Choose the Action Event

    4. Click the Continue button

    5. Select the Account

    6. Indicate what you Action(s) will be taken

    7. Click the Continue button

    8. Click the Test & Review or Test & Continue button

    9. Turn the Zap on by clicking the Turn on Zap button or toggling the slider bar to active
