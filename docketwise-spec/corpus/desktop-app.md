## entry: desktop-app.chrome-app-install
- name: Docketwise Chrome App
- named-by-us: no
- description: Docketwise installs as a desktop app from Google
  Chrome or Microsoft Edge: on any page of the web app
  (app.docketwise.com), an icon in the browser address bar installs
  the app, and the page reopens inside the installed Docketwise
  chrome app window (fx-0241, fx-0242).
- criterion: User clicks the install icon in the address bar on the
  Docketwise web app and confirms -> Docketwise opens as an
  installed desktop app
- sources: fx-0241, fx-0242
- tier: provisional
- detail: Chrome and Edge are the two supported browsers; current
  versions recommended (fx-0242). Help recommends pinning the app
  to the taskbar (fx-0242).
