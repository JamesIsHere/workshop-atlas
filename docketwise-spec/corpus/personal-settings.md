## entry: personal-settings.user-roles
- name: User Roles
- named-by-us: no
- description: Each user carries a User Role label displayed next to
  their name when they are assigned to a matter; any user sets their
  own role under Settings > Personal Information, and admins set
  other users' roles via Settings > User Access > Edit User
  (fx-0224, fx-0225).
- criterion: User enters a role in the User Role field and saves ->
  the role is displayed next to their name where they are assigned
  to a matter
- sources: fx-0224, fx-0225
- tier: provisional
